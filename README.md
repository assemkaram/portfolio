# Assem Karam – Portfolio

A personal portfolio website for **Assem Karam**, a Computer Science and AI student and aspiring Full Stack Developer. The site showcases my projects, skills, and contact information, and includes a downloadable CV.

**Live site:** [assemkaram.github.io/portfolio](https://assemkaram.github.io/portfolio/)

## Features

- Single-page layout with smooth navigation: Home, About, Skills, Projects, and Contact
- Responsive design that works on desktop and mobile
- Project showcase with screenshots, descriptions, and links to live demos
- Downloadable CV (PDF)
- Links to social profiles (LinkedIn, GitHub, X, Instagram)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/assemkaram/portfolio.git
   ```
2. Open the project folder:
   ```bash
   cd portfolio
   ```
3. Open `index.html` in your browser. No build step or dependencies are required.

## Deployment

The site is deployed with GitHub Pages from the `main` branch. To publish your own copy:

1. Go to **Settings → Pages** in your repository.
2. Under **Source**, select the `main` branch and the root folder.
3. Save. The site will be available at `https://<your-username>.github.io/<repo-name>/`.
